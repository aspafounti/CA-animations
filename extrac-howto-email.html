Co-Analyst can now generate stream, graph, and map widgets directly from your conversation. This guide walks through everything you need to get up and running — from starting your first widget to interrogating live data without leaving your view.

01
Starting a Widget
[ GIF: creating a widget ]

How it works

Describe the data, not the widget type

Open Co-Analyst and say what you want to see. Co-Analyst picks the right format — but you can always ask it to switch. Prompts that work well:

"Make a comms stream from the last 30 days — Russian gov sources"
"Map events in [region] over the past 3 months"  ·  "Graph mentions of [keyword] week by week"

02
Working Inside a Widget

Focus mode

Interrogate the data without leaving your view

Once a widget is live, use the focus button to keep the conversation going without switching context. On maps, click into a specific layer and ask questions or adjust filters directly. On graphs, ask for analysis of what's in front of you.

This is where Co-Analyst becomes more than a search tool — you're interrogating the data, not just retrieving it.

03
Injecting Context
[ GIF: @ context injection ]

The @ button

More context, more precise outputs

Use @ to bring in other widgets, specific map layers, or saved Boolean searches. The more context Co-Analyst has, the more precise its outputs.

If a Boolean search is doing the heavy lifting, save it — it's reusable across other widgets without rebuilding from scratch.

Best practices

Get signal, not noise

01

Start broad, then narrow

Generate a stream or map first to get a feel for the data landscape, then use focus mode to drill into what matters.
02

Save searches that work

Boolean searches are reusable across widgets. Build once, apply anywhere — no rebuilding from scratch each session.
03

Specify the data, not the format

Co-Analyst selects the right widget type. Describe exactly what you're tracking — actor, topic, timeframe — and let it pick the view.
04

Stack context with @

The more you give Co-Analyst to work with, the tighter its outputs. Layer multiple widgets or Boolean searches before asking for a summary.
